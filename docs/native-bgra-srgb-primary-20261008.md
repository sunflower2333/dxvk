# Encoded BGRA/BGRX backbuffers and primary contract

Base: 2fbb79131da999d52caa92f7341ac14aca12c212. The driver now creates an internal typeless image only for already supported 8-bit PRESENT backbuffer families and retains the DDI format separately. This makes fully typed backbuffer views real backend views; view admission still checks the original bit-layout family and denies reinterpretation of ordinary fully typed textures. RGBA integer views remain possible within the typeless backbuffer family. Creation does not add bind flags.

BGRA/BGRX sRGB Blt uses compatible UNORM scratch, preserving encoded color values through filtering and conversion. Identity and same-layout sRGB/UNORM casts copy physical bits, including X. X8 sampling reads alpha as1; X bits after filtering/rendering are not treated as defined physical alpha. A typeless PRESENT MSAA source resolves under UNORM interpretation, so black/white physical samples average to128, rather than decode/re-encode to188. X8 MSAA remains rejected. Present uses the same encoded readback/resolve path.

A real BGRA sRGB primary is accepted with the existing BGRA wire code1. Mode metadata retains format91, while the KMD receives the unchanged80-byte v0 allocation and64-byte copy packet. Optional BGRX sRGB copies use existing code2 and NO_SCANOUT; a real BGRX sRGB primary remains denied. Existing SDR scanout, resource ownership, sharing, refresh and callback rules stay intact. No HDR, stereo, flip support, runtime admission masks or default-driver selection changed.
