# Findings

8528 combines cube resource/SRV/scoped-mip production. Native WARP references
are pending under DX10 exclusive ownership. Current private-core d7 hardware
acceptance does not establish8528 or ordinary runtime. Cube-array RTV/DSV
range support is a separate DX11 follow-on; this probe avoids those paths.

Use exact R32_FLOAT integer words. Pitched data has independent row padding.
Point samples cover every face and relative mip of finite and remaining SRVs;
whole-resource readbacks catch non-selected cube/mip modifications.
